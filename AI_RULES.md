## Рабочие правила

- Менять только то, о чём попросил владелец; не переписывать технические объяснения без запроса.
- Проверять факты о браузере, Event Loop, React и Next.js; не использовать неточные упрощения и детские аналогии.
- Сохранять содержание и работающие интерактивные примеры при визуальных правках.
- Перед изменением просматривать текущую версию файлов, чтобы не перезаписать чужие коммиты.
- После правок проверять навигацию, FAQ, адаптивность и поведение скриптов.
- Не публиковать и не пушить по умолчанию при локальной работе. При работе через подключённый GitHub сохранять изменения только по запросу пользователя.
- Отвечать на русском, кратко, с технической терминологией.

## О проекте

- Статическая документация Tech Notes на GitHub Pages.
- Основной сайт: `index.html`.
- Вопросы оформляются как FAQ с закрытыми ответами по умолчанию.
- Темы открываются отдельными страницами, ссылки на разделы — через URL-якоря.
